# 📊 Student Income Dashboard – Power BI

An interactive Power BI dashboard designed to analyze student enrollment, fee collection, payment status, outstanding balances, and income trends.

The dashboard helps educational institutions monitor student fee-related information and understand collection performance across departments, months, and sales executives.

---

## 🎯 Project Objective

The main objective of this project is to create an interactive dashboard that provides a clear overview of student income and fee collection.

The dashboard helps users:

- Monitor total enrolled students
- Analyze total course fee
- Track amount paid by students
- Identify outstanding balances
- Monitor overdue accounts
- Analyze collection by department
- Track monthly collection trends
- Compare sales executive performance
- Understand student payment status

## 📌 Dashboard Features

### 🔹 KPI Cards

The dashboard includes the following key performance indicators:

- Total Students
- Total Course Fee
- Amount Paid
- Balance Due
- Overdue Accounts

### 🔹 Filters / Slicers

Users can filter the dashboard based on:

- Batch
- Department
- Enrollment Month

### 🔹 Collection by Department

A bar chart shows the amount collected from different departments, helping identify departments with higher and lower fee collections.

### 🔹 Payment Status Split

A donut chart represents the distribution of students based on payment status, such as:

- Partially Paid
- Overdue

### 🔹 Monthly Collection Trend

A monthly trend chart shows how the amount paid changes throughout the year.

### 🔹 Sales Executive Analysis

A table provides a comparison of sales executives based on:

- Number of Students
- Amount Paid

## 📈 Insights

Some of the insights available from the dashboard include:

1. Total student enrollment can be monitored from a single dashboard.
2. The dashboard provides a quick comparison between total course fees, collected fees, and outstanding balances.
3. Department-wise collection helps identify departments contributing higher fee revenue.
4. Monthly trends help understand changes in fee collection over time.
5. Payment status analysis helps identify students requiring payment follow-up.
6. Sales executive performance can be compared using student count and amount collected.
7. Interactive filters allow users to explore the data based on batch, department, and enrollment month.
